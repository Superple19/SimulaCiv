# M5-04 M4 Regeneration


Status: current

## Question

Which M4 findings regenerate from committed harnesses and data, and
which A-5 timing conclusions still hold on the reference host?

## Method

The comparison logic is in
[`report_m5_04.py`](../../analysis/simciv_analysis/report_m5_04.py).
Source provenance is resolved through [`sources.toml`](sources.toml);
regeneration outcomes are read separately from the committed M5-04
comparisons. Old-ledger matching is reported only as an informational
comparison and does not populate claim provenance. The deterministic
M4-04 CRN comparison used the explicitly bit-identical M4-07
parallel-only mode. All timing gate processes ran at High priority with
affinity `0x555`; each log has timing markers.
