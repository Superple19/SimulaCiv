# M5-04 M4 Regeneration


Status: current

## Question

Which M4 findings regenerate from committed harnesses and data, and
which A-5 timing conclusions still hold on the reference host?

## Method

The comparison logic is in
[`report_m5_04.py`](../../analysis/simciv_analysis/report_m5_04.py).
Claim carry-over is applied by
[`claims.py`](../../analysis/simciv_analysis/claims.py). Runs used the
committed M4 harnesses; the deterministic M4-04 CRN comparison used the
explicitly bit-identical M4-07 parallel-only mode. All timing gate
processes ran at High priority with affinity `0x555`; each log has
timing markers. The headline table shows explicit `none` where
historical source artifacts were not recoverable.

  remeasured.

  one-shot measurements, not A-5 timing results.
- The M4-05 seed-specific follow-up helper source is incomplete; those
  historical seed records remain unrecoverable.
- The aggregate A-5 gate time excludes deterministic harness wall time,
  which the restored harnesses did not record.
