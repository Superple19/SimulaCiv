# M4-04 CRN Efficiency

**Status:** Report-only experiment complete. M4-04 uses the frozen estimator and replicate rules in [§13](../contracts/M4_COUNTERFACTUAL_CONTRACT.md#13-m4-04-crn-efficiency).

## Workload and method

The experiment used the M3P sustained workload from `crates/sim-model/tests/fixtures/m3p_propagation_sustained.toml`, with population `N = 10,000`, `K = 50`, `k = 8`, `p_local = 0.5`, master seed `81985529216486895`, and initial replicate `7`. Propagation was disabled, leaving profile `m3p`. The branch-point snapshot was created once at day 0. The target was selected by the M4-03 rule (lowest live AgentId in the largest settlement); this was `AgentId(0)` in `GroupId(0)`.

Three interventions were evaluated: target food set to `0`, target health set to `0.01`, and `BaseMetabolicCost` increased by 1% (from `1.0` to the configured `f32` result of `1.01`). Horizons were `{7, 30, 90, 365}`. Each set used 100 paired replicate identities `1..=100`; independent-intervention identities were `100001..=100100`. Paired base values were reused as the independent-base sample as specified by §13.3. Every run restored the same logical branch-point state and graph, changing only the post-branch replicate identity.

For each replicate, all five declared outcomes were extracted from snapshots produced at the relevant day boundary in the same trajectory. Effects are intervention minus base. The report gives paired and independent mean effects, sample variances and estimator variances, the deterministic 10,000-resample percentile ratio interval, and mean paired `|D_H|` and newborn CRN loss. The bootstrap used seed `0xA3_11_70`; cells with observed paired variance zero are reported as `exact (paired variance 0)` without a ratio. Infinite upper limits arise when a bootstrap resample has zero paired variance, following the frozen conservative rule.

Host: AMD Ryzen 5 9600X (6 cores / 12 logical processors), Windows 11 Pro. The release command was `cargo run --release -p sim-model --example m4_04_crn_experiment`. The timer covered the three calls to `run_crn_efficiency` and totaled **4,880.477 seconds (81m20.477s)**; compilation and one-time initial configuration, world, graph, and branch-point snapshot creation were outside that timer. The API runs each paired set through the M4-03 series branch API. For independent intervention identities it uses the M4-02 paired branch API and retains only the intervention side; the API also executes its base side, which is not reused in the estimator. This extra work preserves the existing public execution path but increases compute time.

The run timer was aggregate; simulation, branch-day snapshot encoding, outcome snapshot decoding/extraction, and bootstrap were not separately instrumented. This was a CRN research run rather than a performance gate, so no A-5 timing comparison or gate was performed. The temporary example source was removed after the run; generated CSV files remain under ignored `target/`.

## Findings

### Horizon and divergence

**Measured facts:** At H=7, H=30, and H=90, many outcome cells have exactly zero paired variance and therefore use the frozen exact-zero report; this happens even when independent-set mean differences are nonzero due to sampling variation. Among non-exact cells, the ratio generally favors pairing, but its magnitude varies sharply by outcome and horizon. Examples: the health intervention's mean-health ratio falls from about `8.54×10^6` at H=7 to `7.21` at H=365 while mean `|D_H|` rises from `18.31` to `10,179.19`; the global cost intervention's alive-population ratio falls from `469.7` at H=30 to `22.37` at H=365 while mean `|D_H|` grows from `10,028.04` to `10,303.22`. Food=0 has non-monotone ratios across horizons, including many exact cells, so there is no universal monotone ratio-versus-horizon curve.

**Inference:** For outcomes that become affected as trajectories separate, pairing's variance advantage tends to shrink by H=365 in these examples, even as `|D_H|` approaches the population scale. `|D_H|` alone does not predict the ratio: the estimator depends on the scalar outcome and the covariance retained by shared coordinates.

### Local versus global intervention effects

**Measured facts:** Based on whether the paired-mean 95% interval excludes zero, food=0 has 4 of 20 outcome/horizon cells distinguishable from zero, health=0.01 has 11 of 20, and the global +1% cost change has 10 of 20. At H=365, food=0 is distinguishable only for target-settlement alive population (`−0.10`, interval `[−0.18, −0.03]`); health=0.01 is distinguishable for alive population, total wealth, target-settlement alive population, and target-settlement wealth, while mean health includes zero; all five global-cost outcomes exclude zero. The global-cost intervention has mean `|D_H|` above 10,000 at each horizon, while food and health start at `74.8` and `18.31` on H=7 and exceed 10,000 by H=365.

**Inference:** The global parameter shift becomes visible across the world sooner and in more aggregate outcomes than the two local field overrides. The smaller local interventions still have detectable effects for selected outcomes, but not consistently across all aggregate measures. These intervals describe this configuration and replicate set; they do not establish a general causal ranking across workloads.

### Newborn CRN identity

**Measured fact:** Mean cumulative newborn CRN loss is zero through H=90 for all three interventions, then reaches `1.34` for food=0, `1.43` for health=0.01, and `33.02` for the global cost change at H=365. This 100-replicate experiment therefore observes some lineage-matched births with differing AgentIds, unlike the smaller M4-03 sample; AgentId RNG identity remains unchanged as frozen, and the loss is reported as context rather than corrected.
